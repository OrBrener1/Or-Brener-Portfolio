# Cloud Storage Platform (Google-Drive-like System)

**Advanced Systems Programming Project**

## Overview

A multi-client cloud storage application, built as part of an advanced systems programming course, supporting file upload, download, and synchronization between a server and multiple clients — similar in concept to Google Drive.

## Full project & code

🔗 **[github.com/OrBrener1/Drive-part-5](https://github.com/OrBrener1/Drive-part-5)**

The repository above contains the complete implementation, including the client-server architecture, storage logic, and web interface.

## Key aspects of the project

- Client-server architecture supporting multiple concurrent users
- File storage, retrieval, and synchronization logic
- Web-based interface for interacting with the storage system
- Hands-on experience with networking, concurrency, and system design principles
