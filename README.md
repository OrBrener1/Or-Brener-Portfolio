# Or Brener — Project Portfolio

## 💻 [Cloud Storage Platform (Google-Drive-like System)](./systems-programming-drive-clone)
Advanced Systems Programming project: designed and built a multi-client cloud storage application with a web interface, supporting file upload/download, sharing, and synchronization — similar in concept to Google Drive.
